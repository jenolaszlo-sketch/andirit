`ANDIRIT-CI1A-S2.6-WP-S64-IMPL-01`. The corpus and graph/occurrence ledgers are
prepared here. “Expected” refers to `expected/` artifacts generated by the
independent oracle.

## Implementation requirements

- Add deterministic C1/C2/C3/C4 staging and ledger comparators using existing
  test infrastructure.
- Implement the C4 exact occurrence-contributor ledger from the accepted
  authority and production plugin/repository identities.
- Capture raw mirror node/edge/manifest census at every applicable checkpoint.
- Exercise known-failure and reopen sequences with the existing hook/worker
  patterns.
- Produce exact-candidate Windows x64 and genuine hosted Linux x64 named-case
  receipts; macOS remains a regression gate.

## Known expected deltas (not defects)

The C1 `source-changed` variant inserts documentation lines in addition to
changing one argument. Six `declares` edge IDs therefore change while all node
IDs remain stable. The implementation must compare the frozen delta, not assume
graph invariance. The symbols-core variant likewise replaces one `declares`
edge.

## Not covered here

The full D3 campaign is not executed in this re-entry. H1 historical stores are
not opened in re-entry. DF-1 is not closed. These remain implementation and
independent-qualification subjects.
