# M5.4 preregistered probe plan

Target is R2 `25bc6e3b4305c7ce088deb36cfb000138dc76648` production with the unchanged compilation/resolver implementation on the R3 export. Roslyn package `Microsoft.CodeAnalysis.CSharp` and Common `5.9.0` identify repository commit `35d9211b841e7613c1d2f8f5af6d628ace696c4c`. The probe records the actual loaded assembly informational version and digest. SDK compiler identity is recorded separately by the gate receipts.

| Attempt | Discriminating hypothesis | Expected symbol / association |
| --- | --- | --- |
| `signature` | Omitting an optional parameter with a transitive type avoids naming the type. Roslyn overload binding may still reject the method's use site when the parameter assembly is absent from the caller. | No usable symbol; no resolver entry. If it binds, predict the direct Bridge assembly as owner. |
| `signature-direct` | Adding the explicit reference is the positive control for the exact test call. | Unique ordinary Bridge method, direct source, `Complete`. |
| `retarget` | In a caller without Bridge's Root reference, a signature-independent Bridge method survives reference rebinding in a wrapper, retaining Bridge assembly identity. | Unique ordinary method, distinct underlying assembly symbol with matching identity, direct source, `Complete`. |
| `forwarding` | A framework `System.Uri` static method reached through the ordinary runtime reference set has the destination, rather than forwarding facade, as its owner. | Unique ordinary method, destination PE association, `UnsupportedExternalEvidence`. |

Each configuration uses production `PrepareAnalysisAsync` on ordinary projects and captured platform PEs. A read-only observer inspects semantic symbols, project and PE associations, and the actual resolver with the verified live caller. The candidate scopes are admissible under discovery and verification. The scope may be complete even when a call has a compiler binding diagnostic. No change to source compilation or its verified universe is permitted during the probe. ReferenceManager's compilation-reference assembly wrappers, the overload binder's use-site checks, and forwarding through the destination metadata assembly motivate these distinctions. The experiments do not repeat transitive inheritance or returned-class/interface receivers.

Limit is four configurations in one process, up to five minutes including build. Stop after one pass, a candidate meeting the necessary conditions, or the budget limit. One additional authority-bound publication/reopen configuration is permitted only if a viable candidate actually returns `MissingDefiningCompilation` with a supported usable symbol. Retain diagnostics and false predictions. A failed build can be corrected without adding candidate configurations.
