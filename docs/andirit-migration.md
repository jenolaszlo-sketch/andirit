# Migrating to standalone Andirit

The public naming progression is **Penghou.Hetu → Penghou.Andirit → Andirit**. The first two are historical .NET API identities. **Andirit is the final standalone library identity**; Penghou remains an umbrella ecosystem name.

The active solution is `Andirit.slnx`. Six source assemblies and package IDs are `Andirit`, `Andirit.Abstractions`, `Andirit.CSharp`, `Andirit.TreeSitter`, `Andirit.LatticeDb` and `Andirit.Testing`. Replace historical `Penghou.Hetu[.*]` or unpublished `Penghou.Andirit[.*]` package references with their `Andirit[.*]` counterparts. Change using directives and fully qualified type names to `Andirit` and the existing nested namespace suffixes.

The previous milestone already established `AndiritBuilder`, `AndiritHost`, `AndiritHostBuilder`, `AndiritHostHealth` and `AndiritHostBuilderExtensions`; those short names stay unchanged. Consumers coming directly from Hetu also replace the corresponding Hetu product type names. General CodeGraph types, signatures and behavior stay the same. Namespace/assembly transitions deliberately break source and binary binding: update references and rebuild all affected consumers. No legacy wrapper or forwarding API is added. Penghou.Andirit packages were never published; old published Penghou.Hetu packages remain untouched.

Development version remains `0.2.0-preview.6`. All six standalone packages are packed and exercised through isolated local-feed consumers; **no package publication or release is part of this milestone**. The owner confirms intended publisher `jeno` controls the Andirit prefix. Publication credentials/trusted publishing must still be qualified in a separately authorized release; no publishing operation is used as an availability test.

The canonical GitHub URL is [andirit](https://github.com/jenolaszlo-sketch/andirit) after the gated in-place repository rename. Update origin to `https://github.com/jenolaszlo-sketch/andirit.git`; the old URL redirects. Repository ID 1345607723, history, reviews, tags and archival refs remain unchanged. Canonical checkout stays `D:\projects\Andirit`.

Persisted identities are independent of this public rename. Schema stays 2. Historical `HetuMetadata`, `HetuRepository`, `HetuRun`, `HetuIndexState`, `HetuUnit`, `HetuStage`, `HetuBaseline`, native `HetuGraphNode`/`HetuMirror`, property `hetu_json`, plugin/provider `penghou.hetu.*`, loose C# `Hetu.Loose.CSharp`, TS/JS p9 and graph/publication identity formulas remain intentional protocol identities. Do not rename these strings or rewrite databases. [Current durable qualification](rename/andirit-rename-02/durable-compatibility.md) reuses authentic original Hetu stores and their unchanged expected hashes.

Historical records—including [ANDIRIT-RENAME-01](rename/andirit-rename-01/README.md), [accepted EC-6D owner decisions](decisions/ec6d-owner-01-contract-acceptance.md), reviews and planning—retain their original names and Git bindings. Apply this migration mapping when consuming them as current source guidance; do not rewrite the accepted contracts.

Qualifications remain: Windows-focused cross-version durable evidence; historical unreproducible migration hash; positive-only structural export scope; publication/source snapshot consistency limitations; unmeasured representative performance; R16 intended-consumer validation still open. Next is **EC6D-R16: Intended-Consumer Validation**, followed by separately authorized **EC6D-IMPL-01: TypeScript Interface Consumer Intelligence**. No EC-6D implementation is introduced here.
